# 缺资料时怎样带用户补齐

## 从已收到的资料开始

先读附件、项目目录与已有上下文，列明“已收到／部分覆盖／未提供”。缺哪一类只影响对应判断；不要重复索取可从原件得到的公司信息、域名、市场或已授权工具入口。目录或文件还没有收到时，不能写已经接收、解析或验证。

给用户一个当前最重要、能执行的补数任务：**用途 → 已知工具入口 → 报告 → 国家 → 筛选 → 必留字段 → 回传原文件 → 受限时的替代办法**。一次选用户正在使用的一个工具和一个种子/竞品先做；确认首份原表可用后，再按同口径补剩余名单。用户要完整清单时可提供总览，但不把第一次交互变成长表单。

| 当前情况 | 优先引导 | 同时可以做什么 |
| --- | --- | --- |
| 只有一句“帮我规划网站” | 先问实际产品/服务、目标国家/语言；再确认已有文件及在用工具 | 明确业务范围和本次交付，不虚构竞品数据 |
| 只有`excavator/digger`等种子 | 指导导出第一个种子的包含词拓展表 | 用公司目录整理初步产品维度，标为业务假设 |
| 有种子拓词和竞品排名表，没有合并词库 | 直接接收，由Codex合并去重并保留来源关系 | 无须再问用户要“已完成行业词库” |
| 有排名表但没有竞品名单 | 从域名/URL恢复名单，请用户只补无法判断的分组或理由 | 分析已有词库与URL |
| 有词和排名，缺排名URL列 | 让用户在同一竞品的排名报告启用URL列并重导 | 做词频/语义；页面证据保持待补，不把首页填作缺失URL |
| 只有竞品名单，没有排名表 | 指导导出一个优先竞品的排名1–30关键词及URL | Computer Use看该站菜单和代表页 |
| 只有截图或导出被限行 | 接受可见样本，记录报告总行数与收到行数；按可用条件分批或分站 | 交暂定架构，标明无法覆盖的需求 |
| 低DR/高相关流量只有口头标签 | 先保留为用户提名；请补同工具的权重、引用域、目标国流量及主要排名词/页证据 | 研究已给站点，不能说筛选指标已核验 |
| 缺流量列，但有排名和URL | 不阻断页面结构研究；用户需要流量排序时再补逐词估算或Top Pages原表 | 以排名词/需求覆盖分析，流量写未知 |
| 缺工厂身份/能力证据 | 复用已有企业资料，补当前判断所需的主体、自制/外协范围、工厂图、工艺/检验或适用证书原件；证书要有主体、有效期与适用范围 | 先规划模块与占位；不把工厂、产能或认证写成已经核实 |
| 缺企业目录或经营边界 | 只问会改变拆页的产品、材料、应用或不经营项 | 研究竞品，但正式菜单不采用未确认业务 |

没有任何词表时可以交暂定栏目草案和收集指引；不要强行运行要求词表的生成脚本，也不能用假数据补齐让校验通过。部分资料已够做一条产品线时先交该范围成果，明确未覆盖范围。

## 产品种子拓词：以用户已有工具为准

“精准”指种子准确代表产品；这张输入要扩展出包含该产品词/明确词形变体的搜索短语。不同工具对匹配按钮的命名不同，按实际报告核对，不把相近主题词报告当成包含词导出。

- **Semrush：** 已授权入口 → Keyword Magic Tool → 目标国家 → 每次一个产品种子。使用符合包含产品词要求的匹配范围，检查词形变体及实际返回词；`excavator`与`digger`可分别导出再合并。
- **Ahrefs：** 已授权入口 → Keywords Explorer → 目标国家 → 每个种子的Matching terms（Terms match或所需Phrase match）。Related terms属于另一种扩展来源，若补充使用需单独标来源。
- 保留Keyword、可得Volume/KD/Intent等原列；记录种子、国家、工具、日期、筛选、报告总行数和导出行数。不要只取概览或当前可见几行，也不要要求用户手工改列名。
- “全部”指该工具在指定国家、筛选和当前权限下可得的报告范围。遇到限额先记录，按许可分批；不默认购买服务或要求安装MCP。

## 竞品排名词与URL

用户已提供全部有流量页面、完整排名或更广位置范围时直接接收，不重复索要或要求删去31名以后记录。下列1–30是资料缺失时可先执行的收集范围；另可接收Top Pages页面流量原表，并把它与逐词Traffic分开。商业页、应用页、博客页均保留，按实际页型分别服务核心架构与文章计划。

- **Semrush：** Organic Rankings（旧界面可能称Organic Research）→ Positions → 竞品域名 → 目标国家 → 位置自定义1–30 → 显示URL列 → 导出筛选后的全部可得记录。
- **Ahrefs：** Site Explorer → 竞品域名 → Organic keywords → 目标国家 → Position 1–30 → 核实排名URL随表导出 → 导出全部可得记录。
- 必留Keyword、Position、URL；域名、国家和数据日期可以来自报告上下文，由Codex补来源记录。Volume、Traffic、Intent等已有字段全部保留，不因暂时不用而删掉。
- 此处不再强制加“关键词必须包含excavator/digger”的过滤，以免漏掉型号、材料或应用等相关需求。Codex收到原表后做业务相关性审阅。
- 用户要证明“有流量”而表中没有估算流量时，可补该工具Top Pages原表；URL层面的流量不能复制到每个词后再求和。

## 一次补数任务示例

已知用户用Semrush、目标美国、缺竞品排名URL时，可这样说（实际交互用真实域名替换示例）：

> 现在已经收到词库，缺的是关键词对应的排名页面。请在你正在用的Semrush入口，打开这个竞品的Organic Rankings → Positions，国家保持美国，排名筛选1–30，在列设置里确认包含Keyword、Position和URL，再把筛选结果导出CSV或Excel原文件。已有Volume/Traffic列一起保留。这样我能判断这些需求由类目、产品还是文章页承接。若导出受限，请先保留报告总行数、筛选条件及可见Keyword/Position/URL的截图；我会注明样本范围并继续分析。

完成标准是文件已收到、字段已核对、行数和范围已登记；仅给出指引不算任务完成。补数后复用已做研究与稳定ID，更新受影响判断，避免整轮重跑。

方法入口：[Semrush关键词匹配](https://www.semrush.com/kb/617-keyword-magic-tool-manual)、[Semrush排名与URL导出](https://www.semrush.com/kb/494-organic-rankings-positions-report)、[Ahrefs包含词报告](https://help.ahrefs.com/en/articles/5331899-how-to-use-the-keyword-ideas-reports-in-keywords-explorer)、[Ahrefs估算流量口径](https://help.ahrefs.com/en/articles/1863206-what-is-organic-traffic-in-ahrefs-and-how-do-we-calculate-it)。界面变化时核对当前官方说明与实际账号，不死记按钮位置。
